Novedad en 0.2New in 0.2

Ningún agente nombra un modelo.No agent names a model.

Cada agente declara un tier; qué modelo corre cada tier vive en un solo fichero, models.json, y un script determinista lo resuelve — nunca lo adivina un modelo. Un .swarm/models.json lo sobreescribe por repo, que es como otro host mapea los tiers a sus propios modelos.Each agent declares a tier; which model runs each tier lives in a single file, models.json, and a deterministic script resolves it — a model never guesses. A .swarm/models.json overrides it per repo, which is how another host maps tiers to its own models.

30judgement

Auditar, revisar, juzgar, planificar, orquestar. Nunca cae al modelo de un tier más débil: si se agota la lista, hereda el de la sesión.Audit, review, judge, plan, orchestrate. It never falls to a weaker tier's model: an exhausted list inherits the session model.

8standard

Ejecutar un plan cerrado: escribir código, tests y docs. Si su salida no pasa la verificación, reintenta una vez escalando de tier.Execute a closed plan: write code, tests and docs. If its output fails verification, it retries once on an escalated tier.

7mechanical

Correr scripts, curar memoria, recoger datos del entorno. Lo determinista lo hace un script; el modelo solo el residuo.Run scripts, curate memory, collect environment facts. What's deterministic is done by a script; the model only handles the residue.

El juez ciego se resuelve con --avoid el modelo del autor; si la independencia no se puede demostrar, el panel lo dice en su salida en vez de callarlo.The blind judge is resolved with --avoid the author's model; when independence can't be proven, the panel says so in its output instead of hiding it.

Coste, medidoCost, measured

Núcleo corto, el resto bajo demanda.A short core, the rest on demand.

Cada agente carga solo su fichero núcleo y el skill de protocolo. Lo que necesita solo a veces vive en ficheros que lee cuando una línea WHEN <condición> → Read <ruta> se dispara. Es un invariante con test: un fichero bajo demanda al que nadie apunta, o un núcleo que se pasa de su presupuesto de líneas, rompe la suite.Each agent loads only its core file and the protocol skill. What it needs only sometimes lives in files it reads when a WHEN <condition> → Read <path> line fires. It's a tested invariant: an on-demand file nothing points to, or a core file over its line budget, fails the suite.
