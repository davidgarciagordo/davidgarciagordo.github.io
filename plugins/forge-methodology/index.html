forge-methodology

"A la par con Stripe" deja de significar "hicimos las partes que se nos ocurrieron": cada capacidad de la referencia es una fila, y el PR no se abre hasta que cada una tiene evidencia firmada por alguien que no la construyó. "Parity with Stripe" stops meaning "we built the parts we thought of": every capability of the reference becomes a row, and the PR won't open until each one carries evidence signed by someone who didn't build it.

Qué haceWhat it does

El trabajo asistido por IA falla de dos formas repetibles: se mide contra el propio checklist del ejecutor en vez de contra el objetivo real ("a la par con X" pero solo la mitad de X), y el mismo agente que construye algo se declara a sí mismo verificado. forge-methodology convierte ambos fallos en código: la referencia externa se enumera en un Acceptance Matrix —un req-id por capacidad— y un hook bloquea gh pr create mientras cualquier fila en scope no tenga evidencia real ni un verificador independiente.AI-assisted work fails in two repeatable ways: it gets measured against the executor's own checklist instead of the real goal ("parity with X" but only half of X), and the same agent that built something declares itself verified. forge-methodology turns both failures into code: the external reference is enumerated into an Acceptance Matrix — one req-id per capability — and a hook blocks gh pr create while any in-scope row lacks real evidence or an independent verifier.

Es un guardarraíl del propio agente sobre su gh pr create, no protección del lado del servidor — y, honestamente, es fail-open por defecto: si no encuentra ninguna Acceptance Matrix, avisa pero no bloquea (el repo puede no estar usando Forge ahí). FORGE_REQUIRE_MATRIX=1 lo hace estricto también en ese caso.It's a guardrail on the agent's own gh pr create, not server-side protection — and, honestly, it's fail-open by default: if it finds no Acceptance Matrix at all, it warns but doesn't block (the repo may not be using Forge there). FORGE_REQUIRE_MATRIX=1 makes it strict in that case too.

Ejemplo realReal example

"Fórjalo: añade webhooks de pago idempotentes, a la par con la spec de webhooks de Stripe." Declaras done demasiado pronto y el hook corta gh pr create: FORGE BLOCK — R2 -> no-evidence no-verified-by / R3 -> built≠yes. Corres /forge-verify-matrix, construyes R3, y el mismo comando devuelve Acceptance Matrix COMPLETE."Forge this: add idempotent payment webhooks, parity with Stripe's webhook spec." Declare done too early and the hook cuts gh pr create: FORGE BLOCK — R2 -> no-evidence no-verified-by / R3 -> built≠yes. Run /forge-verify-matrix, build R3, and the same command returns Acceptance Matrix COMPLETE.

Por qué importaWhy it matters

  • Completitud mecánica, no una sensación.Mechanical completeness, not a feeling. "Hecho" deja de ser una opinión del ejecutor y pasa a ser una fila con evidencia o sin ella."Done" stops being the executor's opinion and becomes a row with evidence or without it.

  • El verificador nunca es el ejecutor.The verifier is never the executor. Cada fila necesita un verified-by distinto de quien la construyó.Every row needs a verified-by different from whoever built it.

  • Honesto sobre sus límites.Honest about its limits. Fail-open si no hay matriz, no protección de servidor — lo dice el propio plugin, no hay letra pequeña.Fail-open if there's no matrix, not server-side protection — the plugin says so itself, no fine print.

Cómo se usaHow it's used

Dices "fórjalo: <tarea>, a la par con <referencia>" (o "forge this" en inglés) dentro de Claude Code. El loop de 9 pasos corre solo, interrumpiéndote exactamente dos veces —cada una un multi-select con la recomendación ya marcada— hasta cerrar con el spec, la Acceptance Matrix y el plan versionados en el repo.You say "forge this: <task>, parity with <reference>" inside Claude Code. The 9-step loop runs on its own, interrupting you exactly twice — each one a multi-select with the recommendation already marked — until it closes with the spec, Acceptance Matrix and plan versioned in the repo.
