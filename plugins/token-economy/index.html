token-economy

Cuatro agentes de revisión dejan de pagar cuatro veces por leer los mismos ficheros. Mismos hallazgos, una fracción del gasto en tokens — y la segunda pasada sobre el mismo objetivo sale casi gratis. Four review agents stop paying four times to read the same files. Same findings, a fraction of the token bill — and a second pass on the same target comes out almost free.

Qué haceWhat it does

Cuando una tarea abre varios agentes a la vez —una revisión de código, una auditoría, una migración— cada uno suele re-escanear el mismo repo y redescubrir los mismos hechos. Ese re-escaneo repetido, no las respuestas, es el coste dominante en tokens del trabajo multiagente.When a task fans out several agents at once — a code review, an audit, a migration — each one usually re-scans the same repo and re-discovers the same facts. That repeated re-scanning, not the answers, is the dominant token cost of multi-agent work.

token-economy hace que ese descubrimiento pase una sola vez: un script determinista escribe un context-pack compartido, cada agente lo lee en vez de volver a escanear, y un output-style corta la narración innecesaria del hilo principal. No instalas un comando — se dispara solo cuando el trabajo lo pide.token-economy makes that discovery happen once: a deterministic script writes a shared context-pack, each agent reads it instead of re-scanning, and an output-style cuts unnecessary narration from the main thread. There's no command to run — it triggers itself when the work calls for it.

Ejemplo realReal example

Pides una revisión con 4 lentes (arquitectura, seguridad, rendimiento, datos) sobre un mismo PR. Medido en una pasada real: ~108k tokens por lente si cada una re-lee el repo, ~42k con el pack compartido — el pack en sí cuesta ~74k una vez, amortizado entre las cuatro.You ask for a 4-lens review (architecture, security, performance, data) on the same PR. Measured on a real pass: ~108k tokens per lens if each re-reads the repo, ~42k with the shared pack — the pack itself costs ~74k once, amortized across all four.
