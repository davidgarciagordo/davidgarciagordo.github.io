working-methods

La metodología deja de depender de que el agente se acuerde: las fases son código, no prosa, los gates devuelven un código de salida, y a ti solo te interrumpe dos veces, no todo el rato. The methodology stops depending on the agent remembering it: phases are code, not prose, gates return exit codes, and you're interrupted exactly twice, not constantly.

Qué haceWhat it does

Una metodología que el modelo puede saltarse es una sugerencia. working-methods es la capa de enforcement de la Forja dentro de Claude Code: /forge-run secuencia las 12 fases mediante forge.js, una máquina de estados sin dependencias que rechaza ejecuciones fuera de orden. Un hook delega en ella antes de cada gh pr create — y es fail-closed de verdad: si no puede leer el manifest, se niega a dar el visto bueno en vez de dejar pasar por duda.A methodology the model can skip is a suggestion. working-methods is the enforcement layer of Forge inside Claude Code: /forge-run sequences the 12 phases through forge.js, a zero-dependency state machine that rejects out-of-order runs. A hook defers to it before every gh pr create — and it's genuinely fail-closed: if it can't read the manifest, it refuses to vouch instead of letting it through on doubt.

Además incluye /grill —3-4 lentes read-only adversariales sobre cualquier documento, más una 4ª lente de completitud— y /handoff, el relevo de sesión que se ejecuta solo cuando no hay nadie delante.It also ships /grill — 3-4 read-only adversarial lenses on any document, plus a 4th completeness lens — and /handoff, the session relay that runs itself when nobody is around.
